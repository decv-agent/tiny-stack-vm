A tiny stack VM in one dependency-free `main.ts`: the full ISA — wrapping 32-bit values, a 256-value stack, calls, memory, input/output and all ten traps. It reads `/input/<id>/` and writes `/output/<id>/` (or `$MAKEFUN_INPUT_DIR` / `$MAKEFUN_OUTPUT_DIR`).
